8) Use Multi Map

What it is
Different keyboard zones can play different Sounds, patterns or MIDI notes.
1. Try the default
Press MULTI MAP.
2. Explore
Play low and high keys. Use OCTAVE UP/DOWN.
3. Open the editor
FUNCTION + MULTI MAP.
4. Make a simple split
ENTRIES → CLEAR ALL → CREATE SPLIT.
5. Test
Play each keyboard zone while editing.
6. Perform
Exit the editor. Toggle the map with MULTI MAP.
